# 🔢 Game 2048

**2048 게임판에서 최대 5번 움직였을 때 만들 수 있는 가장 큰 블록**을 구하는 알고리즘 문제 풀이입니다.
(백준 12100번 「2048 (Easy)」 유형)

## 풀이 방법

- 상 / 하 / 좌 / 우 이동 함수를 각각 구현
  - 한 줄씩 보면서 0이 아닌 블록을 밀고, 같은 숫자가 연속되면 한 번만 합침
- 4방향 × 5번 = **4⁵ = 1,024가지 경우를 모두 탐색**(완전 탐색)
- 각 경우의 보드에서 가장 큰 값을 갱신

## 입력 / 출력

```
입력
3
2 2 2
4 4 4
8 8 8

출력
16
```

첫 줄에 보드 크기 N, 다음 N줄에 보드 상태를 입력합니다.

## 실행 방법

```bash
cd src
javac Game_2048.java
java Game_2048
```
